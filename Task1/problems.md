# Аудит безопасности

## Защита информации

- Персональные, медицинские и финансовые данные не защищены шифрованием.
- Нет системы для предотвращения утечек информации.
- Не проводится классификация данных по уровню чувствительности.
- Передача данных между системами (например, из журналов в 1С, из 1С на почтовый сервер Exchange) не защищена
  шифрованием.

## Хранение данных

- Данные хранятся в открытом формате (Excel, PDF, JPG) без шифрования.
- Нет централизованного хранилища.
- Отсутствуют механизмы резервного копирования и аварийного восстановления.
- Не установлены сроки хранения данных.

## Избыточность данных

- При регистрации запрашиваются не только основные данные, которые не требуются в этот момент.

## Управление согласием

- Нет системы для мониторинга согласия пациентов на обработку их данных.
- Отсутствует механизм для отзыва согласия на обработку чувствительных данных.

## Контроль доступа

- Отсутствует ролевое разграничение (RBAC/ABAC).
- Доступ к файлам осуществляется через общие папки без аутентификации.
- Не реализована двухфакторная аутентификация (2FA).

## Аудит

- Действия с данными не фиксируются в логах.
- Отсутствуют инструменты для анализа угроз (SIEM).
- Не отслеживаются аномальные активности.

# Рекомендации

## Инструменты защиты информации

| Тип данных                   | Механизм защиты                                                                                        |
|------------------------------|--------------------------------------------------------------------------------------------------------|
| Медицинские данные пациента  | Шифрование (AES-256), RBAC, абфускация и маскирование для систем анализа данных                        |
| Финансовые данные компании   | Шифрование (AES-256), RBAC                                                                             |
| Платежные данные клиентов    | Шифрование (AES-256), токенизация (для банковских карт), маскирование, защищенный канал передачи (TLS) |
| Складские данные             | RBAC                                                                                                   |
| Персональные данные пациента | Шифрование (AES-256), RBAC, абфускация и маскирование для систем анализа данных                        |
